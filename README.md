# Chubbuck with Maya — concept v0

A small, responsive landing-page experiment for an acting coach using the Chubbuck Technique.

## Preview locally

Open `index.html` in a browser. No installation or build step is required.

For a local web server, run this inside the project folder:

```powershell
python -m http.server 8080
```

Then open `http://localhost:8080`.

## Publish with GitHub Pages

1. Create a GitHub repository and upload this folder.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, select **GitHub Actions**.
4. Push to the `main` branch. The included workflow publishes the site.

The public address will normally be `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Before using it as Maya's real website

- Replace the concept copy with Maya's approved biography, qualifications, services, and wording.
- Confirm how her Chubbuck Technique certification should be described.
- Add her preferred email, booking link, location, and social profiles.
- Replace the generated rehearsal-stage image with Maya's own photography if available.

The hero artwork was AI-generated for this mock and contains no real person.
